## System

| | |
|---|---|
| **Machine** | Lenovo ThinkPad E16 Gen 2 |
| **CPU** | Intel Core Ultra 7 155H |
| **GPU** | Intel Arc (Xe driver) |
| **RAM** | 32GB |
| **OS** | NixOS Unstable |

---

## Stack

| Role | Tool |
|---|---|
| Window Manager | Hyprland |
| Bar | Waybar |
| Terminal | Kitty |
| Shell | Fish + Starship |
| Editor | Zed + Neovim |
| Launcher | Rofi |
| Notifications | Mako |
| Lock Screen | Hyprlock |
| Theme Engine | Stylix |
| Colorscheme | Verdigris (custom base16) |
| Browser | Firefox |

---

## Usage

```bash
git clone https://github.com/YsfOuz/nixos /etc/nixos
nh os switch
```
